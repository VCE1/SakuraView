# SakuraView

Vibe Coding 自用跨平台图站客户端与爬虫浏览器，基于 Flutter 构建，支持 Android、iOS 与 Windows 桌面端。

## 项目说明

- 个人自用项目，由 Vibe Coding 方式迭代完成。
- 仓库不开放 Issue 与 Pull Request，如需自定义功能或适配修改，欢迎直接 Fork 后自行魔改。

## 主要功能

- 多图站支持：适配 danbooru、yande.re、zerochan 等站点的浏览、标签搜索、画质分级与分级过滤。
- 看图与详情：瀑布流浏览、原图按需加载、图组关联查看、本地与云端双模式收藏、本地下载管理与历史记录。
- 桌面端适配：Windows 端支持宽屏侧边导航栏、鼠标悬停与滚轮缩放翻页、快捷键操作及本地下载目录直达。
